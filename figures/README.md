# Figures

The notebook generates quality, cost, and decoding plots into this folder. Open and run MTSystems_en_eo.ipynb from top to bottom to regenerate the PNG files.

The supplied baseline figures/metrics are from compact architectures trained from scratch, plus a pretrained MarianMT reference. They are not results from fine-tuned pretrained mT5 or prompted pretrained LLaMA/Gemma. Those runs are handled separately by pretrained_adaptation.py and write a distinct JSON results file.
